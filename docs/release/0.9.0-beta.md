# StatsTalk 0.9.0 Beta

StatsTalk 0.9 introduces a local-first Windows desktop workflow for common social-science
statistics. An API key and SPSS are optional: reviewed methods can run locally with the
Python backend, while SPSS remains an optional enhanced backend.

## Included

- Eleven public methods: descriptives, frequencies, independent and paired t-tests,
  one-way ANOVA, Pearson and Spearman correlation, chi-square, Mann-Whitney U,
  Wilcoxon signed-rank, and Kruskal-Wallis.
- `.sav`, `.csv`, and explicit single-worksheet `.xlsx` import.
- Local applicability checks, deterministic plain-language results, and advanced evidence.
- Word reports and privacy-safe reproducibility JSON.
- Optional cloud planning and aggregate-only language polish with explicit consent.
- Optional SPSS backend with transparent effective-backend reporting.
- Experimental MCP integration, disabled by default.

## Privacy Summary

Raw data stays on the local machine. API keys use Windows DPAPI and are stored separately
from configuration. Dataset working copies are session-only by default. Crash reporting,
AI polish, restore metadata, and MCP each require explicit opt-in.

## Downloads

- `StatsTalk-0.9.0-beta-windows-x64-setup.exe`: per-user Windows installer.
- `StatsTalk-0.9.0-beta-windows-x64-portable.zip`: no-install portable package.
- `SHA256SUMS.txt`: artifact integrity hashes.

Microsoft Edge WebView2 is recommended for the native desktop window. If it is unavailable,
StatsTalk opens the same token-protected local interface in the default browser.

## Known Limits

- Windows 10/11 x64 only; binaries are not code-signed in this beta.
- SPSS is optional but SPSS automation is Windows-specific.
- MCP is experimental and must be enabled explicitly.
- StatsTalk is a single-user desktop application, not a network service.
- Updates are not downloaded or installed automatically.

Code signing is tracked as a mandatory 1.0 release gate.
