# Domain Documentation

StatsTalk is a single-context repository.

Before architecture, diagnosis, or implementation work:

1. Read `CONTEXT.md` when it exists.
2. Read relevant decisions under `docs/adr/`.
3. Use the project glossary consistently in issues and code.
4. Surface conflicts with existing ADRs explicitly.
5. If these files do not yet exist, continue without treating their absence
   as a blocker.
