# StatsTalk 用户指南

StatsTalk 是一个桌面统计分析工具。用户上传 `.sav`、`.csv` 或 `.xlsx` 数据后，可以用自然语言描述分析需求，系统会自动选择统计方法、执行分析并生成白话解释。

## 启动

```powershell
cd D:\Projects\StatsTalk
.venv\Scripts\activate
python launcher.py
```

只启动 Web API:

```powershell
python snla/ui/server.py
```

桌面启动器会自动打开本次运行的安全本地页面，端口由系统随机分配。只启动 Web API
时，终端会输出一个仅可使用一次的启动链接；服务重启后应使用新链接。

## 基本流程

1. 上传 `.sav`、`.csv` 或 `.xlsx` 文件；Excel 文件需要明确选择一个工作表。
2. 确认变量列表和样本量显示正确。
3. 选择统计方法、变量和显著性水平，或输入需求后点击“本地建议”。
4. 确认建议的方法与变量，然后开始分析。
5. 查看统计结果、白话结论和解释限制。
6. 需要时导出 Word 报告；报告会记录显著性水平。

以上流程不需要 API Key，也不会发起 LLM 请求。API Key 仅用于可选的云端规划或语言润色，
不会决定统计结论。

## 示例问题

| 问题 | 常见方法 |
| --- | --- |
| 计算成绩的平均值和标准差 | 描述性统计 |
| 统计不同班级的人数 | 频率分析 |
| 比较男女成绩差异 | 独立样本 t 检验 |
| 比较训练前后分数 | 配对样本 t 检验 |
| 不同班级成绩是否有差异 | 单因素 ANOVA |
| 年龄和成绩是否相关 | Pearson 相关 |
| 性别和是否通过考试是否有关 | 卡方检验 |
| 数据不满足正态时比较两组 | Mann-Whitney U |

## 数据要求

- `.sav`: 推荐格式，支持 SPSS 变量标签和值标签。
- `.csv`: 第一行必须是列名，推荐 UTF-8 编码。
- `.xlsx`: 仅支持无宏的现代 Excel 格式。StatsTalk 先显示工作表名称和尺寸，明确选表后才加载变量；不会合并多个工作表，公式只读取文件中已有的缓存值。
- Excel 文件不得超过 100 MB 或 500 万个有效单元格。空表、空白或重复表头、合并式多行表头和损坏文件会停止导入并显示修复建议。
- 变量名尽量简短明确。
- 不要把姓名、手机号、身份证号等隐私信息作为变量名。

## 隐私说明

云端规划只接收严格白名单内的变量结构：变量名、类型、标签、分类/连续角色和行列规模。
原始数据行、值标签、文件名、文件路径和统计结果不会进入规划请求。敏感变量的名称和标签会先
在本地替换为 `var_01`、`var_02` 和 `Sensitive variable 01` 这样的占位信息，LLM 返回后再在
本地恢复引用。MCP 返回给宿主的变量目录也使用相同的脱敏规则。

“可选 AI 语言润色”默认关闭，必须在设置中阅读字段说明并主动启用。启用后只发送分析类型、
显著性判定、显著性水平、检验统计量、p 值、均值、效应量、R² 和样本计数等聚合结果；不会
发送原始数据、变量名、标签或文件路径。润色结果单独显示，本地规则生成的解释始终是统计结论
的权威版本；云端不可用或润色关闭时不影响分析和解释。

未配置 API Key 时，上传、本地建议、校验、分析、解释和导出均在本地完成。

## 数据保留与恢复

数据工作副本和分析历史默认只存在于当前会话。正常退出会删除工作副本并清空历史；下次启动
还会清理异常退出遗留的临时目录和旧版会话数据库。StatsTalk 不会为了恢复功能保存私有数据
副本。

设置中的“下次启动时提示恢复原数据文件”默认关闭。启用后，通过桌面原生文件选择器打开数据
时，StatsTalk 只保存原文件路径、文件名和格式，并使用与 API Key 不同的 DPAPI purpose 和独立
文件加密。下次启动会先询问，只有确认后才重新读取原文件。文件已移动、删除，或 Windows
账户变化导致引用无法解密时，程序会停止恢复并提示重新选择。普通浏览器上传无法取得原始路径，
因此始终是不可恢复的临时副本。

“检查本地数据”显示当前会话、工作副本、加密恢复引用和旧版会话文件的数量与大小，不显示内容。
“清除本地数据”会删除这些数据相关产物，但不会删除原始数据文件、应用配置或 API Key。

## API Key 备份

设置中的“导出密钥备份”会生成受密码保护的 `.stkb` 文件。密码至少需要 12 位，
StatsTalk 不保存密码，也无法帮助找回。请将备份文件和密码分开保管。

在新电脑或 Windows 账户中选择“恢复密钥备份”后，StatsTalk 会先验证并解密备份，
再使用当前账户的 Windows DPAPI 重新加密保存。错误密码、损坏文件或保存失败不会覆盖
机器上已有的 API Key。备份文件不包含原 DPAPI 密文，不能替代妥善保管备份密码。

## 常见问题

**没有 SPSS 能用吗？**
可以。偏好设置为 SPSS 但未检测到 `stats.com` 时，已通过 Python 验证的方法会仅在本次
分析中自动使用 Python，原 SPSS 偏好不会改变，结果和 Word 报告会记录实际后端。同一
会话只提示一次；点击提示中的“改用 Python 引擎”才会永久修改偏好。尚未通过 Python
验证的方法会停止并提示检查 SPSS 路径或选择其他方法。

**导出 Word 失败怎么办？**
先确认依赖已安装：`pip install -r requirements.txt`。导出模块依赖 `python-docx`。

**分析时提示已有任务在运行？**
当前版本是单用户设计，同一时间只允许一个分析任务。等待当前任务完成或点击取消。
